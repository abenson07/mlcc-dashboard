# Legacy site (mapleleafcommunity.org / Webflow) → new site redirect audit

Generated by crawling the live `https://mapleleafcommunity.org` (Webflow) site link graph
(46 pages discovered, all returning 200 — the old site does not currently redirect anything)
and cross-referencing each page's content/title against the new Next.js site's routes and data
files (`data/events.ts`, `data/committees.ts`, `data/leaflet-stories.ts`, `data/volunteers.ts`).

Paths not listed below are identical on both sites and need no redirect (e.g. `/`, `/committees`,
`/membership`, `/donate`, `/contact`, `/events`, all matching `/events/{slug}` event pages, and
all matching `/volunteer/{slug}` volunteer pages).

All rules below are implemented as `permanent: true` (301) in `next.config.ts`.

## Method / caveats

- Crawl was a breadth-first traversal from the homepage following every same-domain `<a href>`
  found on each fetched page (46 pages total, converged — no more new links found in later
  rounds). The old site has no `sitemap.xml` or `robots.txt`, so pages orphaned from the current
  nav (no longer linked from anywhere) would not be discovered this way. If Google Search Console
  or old analytics data is available, it's worth cross-checking for additional stale/indexed URLs
  outside this crawl.
- `/committees/template`, `/leaflet/template`, `/meeting-minutes`, `/join-the-board`,
  `/submit-event`, `/submit-story`, `/volunteer/template`, `/about/maple-leaf`, `/board`, and
  `/membership/business` already have temporary (non-301) redirects to `/` in `next.config.ts` —
  those are new-site routes not yet ready for production, unrelated to this legacy-URL audit.
